# Cheers

Community video source plugin for MikuTV on Apple TV.

- **Plugin ID**: `cheers`
- **Kind**: `source`
- **Version**: `1.0.0`
- **License**: Apache-2.0

## Installation

1. Open **MikuTV** on Apple TV.
2. Go to **设置 → 插件管理 → 发现插件** (or install from `souskeisagara/cheers`).
3. Install **Cheers** and select it as your content entry.
